Core Capabilities

Engineered for Reliability & Security

Built with modern technologies across .NET 8, Node.js WebSocket relays, and Android Jetpack Compose.

Instant Workstation Lock

Triggers native Win32 LockWorkStation() instantaneously from your phone. Perfect when you walk away from your desk.

Sleep & Standby Mode

Dispatches Windows Power Management suspend signals via powrprof.dll to put your machine into standby remotely.

Biometric-Guarded Actions

Restart and Shutdown commands are wrapped in androidx.biometric.BiometricPrompt with fingerprint and device lock PIN verification.

Windows System Tray App

Runs silently in the background tray with live status indicators, right-click menu, balloon alerts, and Windows auto-start toggle.

Dynamic 6-Digit PIN Pairing

No hardcoded secrets. Generate a temporary 6-digit numeric PIN on your laptop and verify on your phone to exchange secure tokens.

Strict 1-to-1 Isolation

Only Phone A can command Laptop A. Phone B, Phone C, or any foreign client is strictly blocked with zero access.

Getting Started

Setup & Deployment Guide

Follow these 3 simple steps to connect and secure your Windows machine.

1

Download & Run Windows Agent

Download RemoteLaptopAgent.exe or unzip the package. Run with --tray (or double-click Start-Tray.bat) to launch silently into your taskbar.

2

Enable Auto-Start with Windows

Right-click the tray icon and check Start with Windows. The agent registers in HKCU Run to protect your laptop automatically on login.

3

Request Pairing PIN

Click Pair New Phone... in the tray menu. A 6-digit numeric PIN will appear on your screen (valid for 5 minutes).

PowerShell (Windows Desktop Agent) 
# Launch downloaded agent in silent Windows System Tray mode
.\RemoteLaptopAgent.exe --tray

# Or run interactive configuration menu with pairing & tests
.\RemoteLaptopAgent.exe
1

Install the Remote Laptop App

Download RemoteLaptopControl.apk directly or scan the QR code above to install on your smartphone.

2

Enter the 6-Digit PIN

Open the app and enter the 6-digit PIN displayed on your laptop. The app contacts the relay and receives a secure 256-bit token.

3

Status Turns Online

The status badge illuminates Green, and instant workstation commands become active.

Bash / Terminal (Android App Install) 
# Install downloaded APK on attached Android device via ADB (optional)
adb install -r RemoteLaptopControl.apk
1

Zero-Friction Lock & Sleep

Tap LOCK or SLEEP for immediate 1-tap workstation standby.

2

Hardware-Guarded Restart & Shutdown

Destructive commands display a purple GUARDED badge and require Android biometric fingerprint or screen lock PIN authentication.

3

Graceful Emulator Fallback

Devices without enrolled biometrics display a safety confirmation dialog so you are never locked out.

Kotlin (BiometricPrompt Guard) 
// MainControlScreen.kt
fun triggerProtectedCommand(cmd: String) {
  biometricHelper.authenticate(
    title = "Authorize $cmd",
    subtitle = "Confirm with biometric or device PIN",
    onSuccess = { webSocketManager.sendCommand(cmd) },
    onError = { showSnackbar("Canceled") }
  )
}
