=====================================================================
               Remote Laptop Control - Windows Agent
=====================================================================

QUICK START:
1. Double-click "RemoteLaptopAgent.exe" to open the desktop application.
   - This executable is SELF-CONTAINED: all dependencies (.NET 8 runtime)
     are bundled directly inside. It runs on Windows 10 & 11 without
     requiring you to download or install .NET first!

2. If you are on an older or enterprise Windows machine and prefer to
   install the official system-wide Microsoft .NET 8 Desktop Runtime,
   simply run "Install-Dependencies.bat" (Run as Administrator).

FEATURES:
- Native Desktop GUI Window (no command prompt/terminal window).
- Displays a real-time 6-digit dynamic pairing PIN on startup.
- As soon as your phone finishes connecting, the app celebrates and
  automatically minimizes to the Windows System Tray (Taskbar Notification area).
- Double-click the system tray icon anytime to restore the window.
- Right-click the system tray icon to Lock Workstation, Reset Pairing,
  or toggle "Start with Windows".
